# 🛠️ CLANDEQ: РУКОВОДСТВО ПО РАЗВЕРТЫВАНИЮ И СБОРКЕ (DEPLOY & BUILD)

Это руководство предназначено для системного архитектора и содержит пошаговые инструкции по развертыванию Go-бэкенда в Docker и конфигурации нативной сборки мобильного iOS/watchOS-приложения в среде Xcode (на Mac или в macOS VM / VMware).

---

## 🐋 ЧАСТЬ 1. РАЗВЕРТЫВАНИЕ GO-БЭКЕНДА (DOCKER)

Бэкенд спроектирован с учетом стандартов безопасных 12-факторных приложений и упакован в защищенный двухэтапный Docker-контейнер без root-прав.

### 1.1 Быстрый запуск локального окружения СУБД Postgres 16

Для поднятия базы данных используйте Docker Compose. Находясь в корне проекта `clandeq/`, выполните:

```bash
# Запуск контейнера СУБД в фоновом режиме
docker-compose up -d

# Проверка статуса контейнера и здоровья (healthcheck)
docker-compose ps
```

При этом поднимется база данных `clandeq` с пользователем `clandeq_admin` на порту `5432`. Хранилище Postgres примонтировано локально как Docker Volume (`postgres_data`), что предотвращает потерю данных при перезапусках.

### 1.2 Сборка и запуск контейнера Бэкенда Clandeq

Соберите production-ready образ бэкенда и запустите его с пробросом ключа Gemini API:

```bash
# Сборка Docker-образа бэкенда
docker build -t clandeq-backend:latest .

# Запуск контейнера бэкенда с пробросом портов и монтированием диска
docker run -d \
  --name clandeq-api \
  -p 8080:8080 \
  -e GEMINI_API_KEY="ВАШ_НАСТОЯЩИЙ_GEMINI_API_KEY" \
  -e PORT=8080 \
  -e STORAGE_DIR="/app/storage" \
  -v clandeq_sqlite_storage:/app/storage \
  clandeq-backend:latest
```

### 1.3 Проверка работы API

Убедитесь, что сервер работает и отвечает на запросы. Сделайте тестовый вызов API синхронизации сделки:

```bash
# Тестовая инициализация и компиляция SQLite
curl -X POST http://localhost:8080/api/v1/deals/test-deal-uuid-1234/sync
```

**Ожидаемый ответ:**

## 📱 ЧАСТЬ 2. НАСТРОЙКА И СБОРКА IOS/WATCHOS ПРОЕКТА В XCODE

Поскольку iOS/watchOS клиент Clandeq работает в жестком оффлайне и использует низкоуровневые аппаратные возможности (CoreML, CoreHaptics, AVFoundation), его необходимо правильно настроить и собрать в IDE Xcode на физическом компьютере Mac или в виртуальной машине (например, VMware macOS).

### 2.1 Подготовка файлов к импорту

Перенесите содержимое папки `clandeq/ios_app/Clandeq` на ваш Mac.

1. **Создайте новый проект в Xcode:**
   * Откройте Xcode. Нажмите **File -> New -> Project**.
   * Выберите шаблон **iOS App with Watch App** (для одновременного создания связки iOS и watchOS клиента).
   * Имя проекта: `Clandeq`.
   * Язык: **Swift**.
   * Интерфейс: **SwiftUI**.

2. **Импортируйте Swift-файлы ядра:**
   * Перетащите следующие файлы из папки `Clandeq` в дерево вашего Xcode-проекта (убедитесь, что галочка **"Copy items if needed"** и таргет **Clandeq (iOS)** выбраны):
     - `NetworkManager.swift`
     - `DatabaseManager.swift`
     - `AudioCaptureService.swift`
     - `AcousticAnalyzer.swift`
     - `ClandeqEngine.swift`
     - `WatchSessionManager.swift`
     - `HapticManager.swift`

### 2.2 Настройка зависимостей и системных библиотек

Наш `DatabaseManager.swift` использует низкоуровневые си-биндинги к библиотеке `sqlite3` для поддержки FTS5. Xcode имеет встроенную поддержку sqlite3, её нужно просто прилинковать к проекту.

1. В Xcode выберите корень вашего проекта в левом меню (синяя иконка).
2. Выберите таргет **Clandeq (iOS)**.
3. Перейдите во вкладку **General**.
4. Прокрутите вниз до раздела **Frameworks, Libraries, and Embedded Content**.
5. Нажмите кнопку **"+"** и введите в поиск **`libsqlite3.tbd`**. Выберите её и нажмите **Add**.
6. Перейдите во вкладку **Build Settings**, найдите параметр **`Other Linker Flags`** и добавьте значение **`-lsqlite3`**.

### 2.3 Настройка разрешений (Capabilities & Info.plist)

Для фоновой записи звука и тактильных пульсаций необходимо настроить права безопасности iOS/watchOS.

#### А. Разрешение на запись микрофона (iOS):
1. Откройте файл `Info.plist` вашего iOS таргета или перейдите во вкладку **Info** настроек таргета.
2. Добавьте ключ: **`Privacy - Microphone Usage Description`** (в коде `NSMicrophoneUsageDescription`).
3. Значение: *"Приложение Clandeq требует доступ к микрофону для анализа тональности, стресса и оффлайн-транскрибации переговоров в режиме реального времени."*

#### Б. Фоновые режимы (Background Modes):
Чтобы захват звука продолжался, когда телефон заблокирован или лежит в кармане:
1. Выберите таргет **Clandeq (iOS)**.
2. Перейдите во вкладку **Signing & Capabilities**.
3. Нажмите кнопку **"+ Capability"** в левом верхнем углу.
4. Выберите **Background Modes**.
5. Поставьте галочки напротив:
   * **`Audio, AirPlay, and Picture in Picture`** (для беспрепятственной фоновой работы AVAudioEngine).
   * **`Background processing`** (для фоновой синхронизации баз).

### 2.4 Настройка watchOS-компаньона

Для вывода тактильной отдачи и текста на часы Apple Watch:

1. Перенесите `WatchSessionManager.swift` и `HapticManager.swift` также в таргет **Clandeq Watch App** (чтобы они были скомпилированы и на стороне часов).
2. Для watchOS таргета во вкладке **Signing & Capabilities** добавьте Capability **`Background Modes`** и выберите **`Workout Processing`** или **`Session Tracker`** (это гарантирует, что часы не уснут во время часовой встречи и будут продолжать считывать haptic-события).

### 2.5 Тестирование на симуляторе и физическом устройстве

1. **Запуск сервера:** Убедитесь, что ваш Go-бэкенд доступен по локальной сети. Если вы тестируете в симуляторе Xcode, он может стучаться на `http://localhost:8080`. Если вы тестируете на реальном iPhone, измените IP-адрес в `NetworkManager.swift` на локальный IP вашего компьютера (например, `http://192.168.1.50:8080`).
2. **Сборка проекта:** Нажмите **Cmd + R** для компиляции и запуска приложения.
3. При первом запуске на устройстве примите запрос на разрешение использования микрофона.
4. Вызовите метод `ClandeqEngine.shared.startNegotiationSession()` с ID сделки — приложение скачает базу с бэкенда, инициализирует FTS-индекс, включит микрофон в фоне и будет готово слать триггеры на часы при симуляции фраз (например, вызов `ClandeqEngine.shared.processRecognizedText("Алексей говорит, что это дорого")` моментально вызовет мягкий вибро-сигнал на руке переговорщика).
